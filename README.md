## Featured Projects

### 01 · [MPPT Controller for Photovoltaic Systems — Graduation Thesis](https://github.com/Durghamrabee/photovoltaic-mppt-thesis)

**Renewable Energy · Power Electronics · MATLAB/Simulink · Proteus · Arduino**

A graduation research project focused on **Maximum Power Point Tracking (MPPT)** for photovoltaic systems. The thesis covers the design and evaluation of MPPT approaches, including Perturb & Observe (P&O), Incremental Conductance (INC), and adaptive/variable-step methods, in the context of a DC–DC buck converter.

- **Institution:** Al-Muthanna University, College of Engineering
- **Authors:** Durgham Rabee and Zainab Zahed
- **Supervisor:** Dr. Aws H. Jrew
- **Published material:** Graduation thesis PDF only. The original simulation, circuit, and firmware source files are not included in this repository.

**[View repository](https://github.com/Durghamrabee/photovoltaic-mppt-thesis)** · **[Read the thesis (PDF)](https://github.com/Durghamrabee/photovoltaic-mppt-thesis/blob/main/MPPT_Controller_for_Photovoltaic_Systems_Graduation_Thesis_2026.pdf)**

### 02 · [Advanced Motor Start/Stop Control — Zelio Logic PLC](https://github.com/Durghamrabee/zelio-plc-motor-control)

**Industrial Automation · Ladder Logic · Schneider Electric Zelio Soft 2**

A documented PLC motor-control logic project for the **Zelio Logic SR3B261BD**. It includes manual/automatic operation, timed startup, status indication, fault and feedback monitoring, and maintenance reminders.

- **Published material:** Native `.zm2` program, exported ladder-logic PDF, diagrams, and technical documentation.
- **Validation note:** The published report records simulation results; independent physical commissioning or safety certification is **not** claimed.
- **Safety:** Educational control logic, not a substitute for hardware safety and protection systems.

**[View repository and project files](https://github.com/Durghamrabee/zelio-plc-motor-control)**
