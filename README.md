## Selected Engineering Work

### 01 — [MPPT Controller for Photovoltaic Systems](https://github.com/Durghamrabee/photovoltaic-mppt-thesis)

**Graduation thesis · Renewable Energy / Power Electronics**

A study of **Maximum Power Point Tracking (MPPT)** for photovoltaic systems, covering Perturb & Observe (P&O), Incremental Conductance (INC), and adaptive or variable-step approaches in the context of a DC–DC buck converter. The thesis documents work involving MATLAB/Simulink, Proteus, and an Arduino-based implementation.

### 02 — [Advanced Motor Start/Stop Control](https://github.com/Durghamrabee/zelio-plc-motor-control)

**Schneider Zelio Logic · Ladder Diagram (LD) · Industrial Automation**

Documented PLC control logic targeting the **Schneider Electric Zelio Logic SR3B261BD**. The design includes:

- Manual and automatic operating modes
- Timed startup and warning indication
- Overload and contactor-feedback monitoring
- Fault acknowledgement and maintenance indication

| Project details | |
| :--- | :--- |
| Native project | **Zelio Soft 2 `.zm2` file** |
| Documentation | **6-page ladder-logic PDF**, diagrams, I/O mapping, control logic notes |
| Verification scope | Simulation results are reported in the project documentation; **independent hardware commissioning is not claimed** |
| Safety scope | Educational control design, **not** a certified machine-safety system |

**[View project](https://github.com/Durghamrabee/zelio-plc-motor-control)** &nbsp;·&nbsp; **[Original PLC file](https://github.com/Durghamrabee/zelio-plc-motor-control/blob/main/source/Project_01_Start_Stop.zm2)** &nbsp;·&nbsp; **[Ladder report](https://github.com/Durghamrabee/zelio-plc-motor-control/blob/main/docs/Project_01_Start_Stop.pdf)**

## Engineering Approach

**Requirements → Design → Simulation / Prototyping → Verification → Documentation**

I aim to make engineering work **traceable and reproducible**: state design assumptions, explain control sequences, provide source material when available, and distinguish modeled performance from independently tested hardware results.
